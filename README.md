## 💡 Problem Statement — Campus Circular

### **From Ownership to Access**

The challenge was to build a campus ecosystem that enables students to make better use of resources already available within their college community.

The platform was designed around:

→ 🔎 Resource discovery  
→ 🤝 Borrowing & lending  
→ 🛍️ Buying & selling  
→ 💬 User–owner communication  
→ ⭐ Trust and ratings  
→ 🔄 Complete exchange lifecycle

The objective was to move beyond simple resource listing and create a more complete and trusted campus-sharing experience.

## 🤖 AI Camera & Object Detection

One of the notable features of the prototype is its browser-based camera workflow.

### Technology Used

- 📷 Browser Camera API
- 🧠 TensorFlow.js
- 🔍 COCO-SSD

### Workflow

**Open Camera → Detect Object → Capture Image → Generate Listing → Edit Details → Publish**

The prototype uses client-side object detection to help users create a resource listing from a captured item.
