Technical scope

No backend required

Mock data

Simulated everything else

Borrowing, payments, approvals, returns, settlements and disputes are all simulated in the frontend.

The technology, UI/UX, screen count, navigation and implementation approach here were chosen freely, with the focus kept on covering the core problem and required functionality end to end. The objective is a trusted digital campus ecosystem that makes sharing practical, safe and convenient, from discovering a resource to returning it responsibly and settling the exchange.

Key functionalities

Thirteen pieces, one trusted loop.

Borrowing lifecycle

Every exchange, visualised end to end.

The lifecycle is simulated and displayed visually so both sides always know exactly where a resource stands.

Late return, damage & settlement

Applicable late fees are calculated and reflected in the final settlement. If damage or loss is reported, users can submit evidence, raise a dispute, and track its status through to resolution.

Before & after condition tracking

The condition of a resource is recorded before borrowing and after return using images, checklists, ratings or other suitable interfaces — so both parties can confirm the exchange fairly.

Platform fee

A configurable platform / service fee applies to eligible exchanges, shown plainly on every transaction and in the admin dashboard.

Borrowing Charge + Platform Fee + Security Deposit = Transaction Amount

Admin panel

One dashboard to run the whole exchange.

A separate admin login and dashboard for managing the platform.
